# Interactive Quiz Application

## About

The Interactive Quiz Application is a simple web-based project that allows users to answer quiz questions and view their final score.

## Features

* Displays quiz questions with multiple options.
* Allows users to select answers.
* Calculates the final score.
* Shows the result after completing the quiz.
* Simple and user-friendly interface.

## Technologies Used

* HTML
* CSS
* JavaScript

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

## Learning Outcomes

* Practiced HTML page structure.
* Improved CSS styling skills.
* Learned JavaScript logic and event handling.
* Implemented score calculation.
